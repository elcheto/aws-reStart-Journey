# aws-reStart-Journey

AWS re/Start Program – Learning Journey (12 Weeks)
Overview

This repository documents my hands-on learning journey through the AWS re/Start Cloud Practitioner Program. Over 12 weeks, I am building practical cloud computing skills through daily labs, projects, and real-world scenarios.

The program focuses on core cloud concepts, Linux, networking, security, automation, and AWS services, preparing participants for roles such as Cloud Support Associate, Cloud Operations Engineer, and Junior DevOps Engineer.

As a QA Engineer with automation experience, I am expanding my expertise into cloud infrastructure, deployment, monitoring, and security best practices.

Learning Goals

Build a strong foundation in cloud computing and AWS architecture

Gain hands-on experience with AWS services and cloud environments

Practice Linux administration and networking fundamentals

Learn automation and infrastructure management

Understand security, monitoring, and cost optimization

Apply DevOps principles in cloud environments
